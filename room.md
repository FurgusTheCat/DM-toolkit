# Room Descriptor — Tag-driven

This standalone tool creates varied room descriptions influenced by tags (e.g. dungeon, tavern, temple).
It lives on room.html and uses templates which bias phrasing, props, and sensory details based on the selected tags.

Use the UI on the Room Descriptor page to:
- Select one or more tags (dungeon, tavern, temple, library, keep, cave, crypt, market)
- Enter optional props or NPC hints
- Choose complexity: short, medium, long
- Generate a description that incorporates tag-driven vocabulary and hooks
